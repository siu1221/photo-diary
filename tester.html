📖 하루 한 장 테스터 안내

사진 한 장으로 하루를 남기는 일기 앱이에요. 써 보면서 이상한 점이나 불편한 점을 알려 주세요!

1. 앱 설치하기 (갤럭시)

  1. 아래 앱 열기 버튼을 눌러요 (삼성 인터넷이나 크롬에서 열어 주세요. 카톡 안 브라우저 말고요!)
  2. 크롬: 오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치 → 설치
  3. 삼성 인터넷: 아래 ≡ → 현재 페이지 추가 → 홈 화면 (주소창에 ⬇ 설치 아이콘이 보이면 그걸 눌러도 돼요)
  4. 홈 화면에 생긴 하루 한 장 아이콘으로 열면 앱처럼 쓸 수 있어요
앱 열기

카톡에서 링크를 눌렀다면 오른쪽 아래(또는 위) ⋮ → 다른 브라우저로 열기를 먼저 눌러 주세요.

2. 이것저것 써 보기

  • 달력에서 날짜를 눌러 사진·영상 올리기 (여러 장, 편집·순서 바꾸기)
  • 노래 고르기 (애플 미리듣기 / 유튜브 링크), 음성 녹음, 일정, 오늘의 한 마디
  • 저장한 날을 다시 열었을 때 노래가 나오는지
  • ⋯ 메뉴의 백업 파일 만들기 / 불러오기
  • 화면 왼쪽 끝을 오른쪽으로 밀어서 뒤로 가기

3. 알려 주기

이상했던 점을 적고 복사하기를 눌러 카톡으로 보내 주세요. (어디서, 뭘 눌렀더니, 어떻게 됐는지)

※ 기록은 이 폰 안에만 저장돼요 (서버로 보내지 않아요). 앱을 지우거나 브라우저 데이터를 지우면 기록도 사라지니, 중요한 건 백업 파일로 보관해 주세요.
